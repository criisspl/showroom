---
name: grill-me
description: Use when the user shares a plan, feature idea or design and asks to be grilled, stress-tested or challenged before implementing it.
disable-model-invocation: true
---

Interrógame sobre este plan hasta que tengamos una visión compartida.

- Recorre el árbol de decisiones rama a rama y resuelve las dependencias entre decisiones de una en una.
- Una o dos preguntas por turno, de la más estructural a la más concreta.
- Busca casos límite: datos vacíos, errores de red, concurrencia, estados de carga, móvil, accesibilidad.
- Si una pregunta se puede responder mirando el código, mira el código en vez de preguntar.
- Cuando no queden ramas abiertas, resume las decisiones tomadas en una lista corta.
